# Arquivo legado — Cloudflare não utilizado

A implementação Cloudflare Worker + D1 foi mantida apenas como referência antiga. A configuração escolhida para o projeto XP Battery é um servidor próprio Node.js + SQLite, sem Cloudflare nem Firebase.

Para instalar e publicar a API escolhida, segue as instruções em [backend/self-hosted/README.md](../self-hosted/README.md). O workflow antigo de implantação Cloudflare foi removido para evitar confusão.
