Abrir o painel do telefone

Os dados ficam numa base de dados SQLite dentro do telefone Android. Esta página pública não consegue ler essa base de dados diretamente. Para ver os dados reais, abre o painel servido pelo próprio XP Battery na rede local.

1

Abre o APK XP Battery no telefone que será monitorizado e mantém a aplicação aberta.

2

Copia o endereço local mostrado no ecrã do APK. Os dois telefones devem estar ligados à mesma rede Wi-Fi.

3

Cola o endereço abaixo e abre o painel local. No painel, introduz o código de acesso mostrado no APK.

Usa apenas uma rede privada de confiança. A ligação HTTP local não é cifrada; nunca exponhas a porta 8765 à Internet.
